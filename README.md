This project is a desktop-based invitation management system developed during my internship at Mersin University IT Department. 
The application allows users to register, generate personalized invitations, and access customized content through unique QR codes.

The system is designed with a flexible structure, enabling the creation of different user groups with unique features and content.

Features
User registration and management
Personalized invitation generation
Unique QR code integration for each user
Group-based content and feature customization
Desktop application interface (Java Swing)
Full-stack structure (Backend & Frontend integration)

Technologies Used
Java (Swing) – Desktop application
Java Spring – Backend development
JavaScript, HTML, CSS – Frontend development
MSSQL – Database management
QR Code Integration – Personalized user interaction

Purpose
To provide a personalized user experience
To enable secure and unique identification using QR codes
To improve invitation and event management processes
To demonstrate full-stack development skills in a real-world project

Outcomes
Gained experience in full-stack development
Improved skills in Java Swing & Spring integration
Learned database design and QR-based systems
Developed a scalable and modular system architecture
